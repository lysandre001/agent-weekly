## 要点

- 作者以 Anthropic 招聘经理身份宣布：他的团队废除了传统 coding interview，理由是 Claude 在小型 React 挑战和汇编问答上都已强于人类，面试不再提供信号。
- 核心判断：AI 编码让"影响力不再受限于积累了多少年框架知识"，初级工程师正在越过资深工程师——"Hunger beats tenure"。目标读者实为"没有社会资本、地位、权力的人"。
- 论证链：新人的"无知优势"（James March 1991 组织学习论文、Patrick Collison 对 Stripe 新人的告诫、Orson Welles"纯粹的无知"访谈）→ 但组织里没人听新人说话（"All vision, no voice"）→ 过去执行成本高、必须熬资历才能让别人为你的想法下注 → 现在执行不再昂贵，赌一次只需要一个周末原型。
- 五条建议：① 选业务影响而非 backlog（引 Patrick McKenzie 2011《Don't Call Yourself a Programmer》）；② 选一个激进的想法；③ 一个周末做出来；④ 一个好想法打透，不要塞 20 个；⑤ 利用新人视角（对用户同理心 + 不知道哪些事"不可能"）。
- 例证：Notion 面试"离线模式是 trick interview"的轶事；Ji Pei 入职一年把作者没推动成功的 dashboard 电视墙第二天搞定（"I had become the old-timer"）；Anthropic 内部 Anthony Morris 和 Alice Zhao 两个新人周末做出 Claude Code 图形界面的原型，约 8 天后公开发布（即后来的 Claude Code GUI 产品）。
- 结尾信号：作者说自己在简历和作品集里找的是"表现出品味、同理心和有原则的思考的"小原型，并公开求更好的 AI 时代面试方法。

## 与本周刊素材的潜在勾连

- 和 koomen"AI 强化康威定律"可放同一议题簇：都在讲 AI 改变组织内权力的分配方式（执行成本坍塌 → 资历贬值 → 协调者/有 hunger 的人升值）。
- 与"编码 Agent 狂热是逃避"（trq212）构成对照：Rieseberg 讲"周末原型"是 hunger 的正向信号，trq212 讲的是同一行为可能是逃避——一组可用作周刊内部张力的小对位。
